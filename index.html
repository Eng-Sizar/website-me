نبذة عني

مطور يجمع بين الانضباط الهندسي والذوق البصري الرفيع.

الاهتمام بأدق التفاصيل هو ما يحوّل الكود البرمجي العادي إلى تجربة رقمية استثنائية تدوم وتلهم المستخدمين.

أنا حمزة هشام، مبرمج أول ومطور تطبيقات ويب شامل (Full Stack)، أركز على بناء وتطوير حلول ويب عصرية تتسم بالسرعة الفائقة، والتجاوب مع مختلف الشاشات، وسهولة التوسع والصيانة على المدى الطويل.

01

إتقان الواجهات الأمامية

بناء واجهات متجاوبة، تفاعلات وحركات سلسة، وتنسيق أنظمة تصميم CSS/SCSS نظيفة ومطابقة لأحدث المعايير.

02

هندسة الخوادم وقواعد البيانات

بناء واجهات برمجة التطبيقات (RESTful APIs)، خدمات Node.js و Express.js، وحلول إدارة ومعالجة البيانات الآمنة.

المهارات التقنية

مكدس تقني متين لبناء وتطوير تطبيقات ويب قياسية وقابلة للتوسع.

HTML5 & Semantic Web

هيكلية دلالية دقيقة، توافق تام مع معايير الوصول (Accessibility)، وبنية مهيأة لمحركات البحث (SEO).

CSS3 & SCSS & Bootstrap

أنظمة تصميم حديثة، تقسيم SCSS منظم (Partials & Mixins)، وحلول Bootstrap 5.3 RTL متقدمة.

JavaScript (ES6+) & jQuery

تفاعلات حيوية، معالجة عناصر DOM بكفاءة عبر jQuery، واستدعاء غير متزامن للبيانات عبر AJAX.

TypeScript

كود برمجي محصّن بالأنماط الثابتة (Static Types)، تقليل الأخطاء البرمجية، وهندسة أنظمة ضخمة.

Node.js

تطوير بيئات تشغيل خلفية فائقة السرعة، خدمات الويب، وتطبيقات الوقت الفعلي (Real-time Web).

Express.js

معمارية واجهات RESTful، طبقات Middleware الآمنة، إدارة التوجيه، والربط مع قواعد البيانات.

C++

كتابة خوارزميات برمجية عالية الأداء، فهم عميق لإدارة الذاكرة، وأساسيات علوم الحاسب المتقدمة.

C# & .NET

البرمجة كائنية التوجه (OOP)، تطبيقات منصة .NET، وبناء خدمات ومنظومات مؤسسية متكاملة.

مسار الخبرة

ثلاث سنوات من تحويل الأفكار إلى منتجات ويب رائدة ومستقرة.

السنة الأولى

الأسس البرمجية المتينة

بناء ركائز صلبة ومتقنة في لغات HTML و CSS و JavaScript و C++ و C#، مع ترسيخ أسلوب التفكير المنطقي وحل المشكلات الهندسية النظيفة.

السنة الثانية

تطوير الويب الشامل (Full Stack)

التوسع في خدمات Node.js و Express.js و TypeScript، ودمج سير العمل الكامل بين واجهات المستخدم الأمامية والأنظمة الخلفية وقواعد البيانات.

السنة الثالثة

هندسة متقدمة وإتقان احترافي

التركيز على المعمارية البرمجية النظيفة (Clean Architecture)، دقة الواجهات البصرية، تحسين الأداء وسرعة التحميل، وسهولة التوسع المستمر.

المشاريع المختارة

الملف: variants/react/Portfolio.jsx • دمج React Hooks مع jQuery و Bootstrap 5.3 RTL. 
// React Component Variant
// الملف: variants/react/Portfolio.jsx
import React, { useEffect, useState, useRef } from 'react';
import $ from 'jquery';
import 'bootstrap/dist/css/bootstrap.rtl.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';
import './scss/main.scss';

export default function Portfolio() {
  const [isScrolled, setIsScrolled] = useState(false);
  const particlesRef = useRef(null);

  useEffect(() => {
    const handleScroll = () => setIsScrolled(window.scrollY > 20);
    window.addEventListener('scroll', handleScroll);

    // jQuery DOM Manipulation
    if (particlesRef.current) {
      const $container = $(particlesRef.current);
      for (let i = 0; i < 30; i++) {
        $('<span class="particle"></span>').appendTo($container);
      }
    }
    return () => window.removeEventListener('scroll', handleScroll);
  }, []);

  return (
    <div className="portfolio-react-app" dir="rtl">
      ...
    </div>
  );
}
